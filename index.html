About this site

This site was built for the Durham University computer science practical on collaborating with git. We worked from one shared GitHub repository, each committing our own pages, pulling each other's changes and resolving conflicts along the way.

The pages share a Bootstrap theme and navigation bar, and are published with GitHub Pages.
